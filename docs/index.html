Features

Everything a production LLM API needs

🔒
Hardware-isolated VPC

Model weights, prompts, and completions never leave your GCP project. Zero data egress to third-party APIs.

⚡
Sub-millisecond auth

API key validation via Argon2id + PostgreSQL. In-memory routing table hot-reloaded without restarts.

📊
Hard budget caps

Per-deployment daily and monthly USD caps backed by BigQuery spend data. Scale to zero when caps hit.

🔑
Scoped API keys

Per-key RPM/TPM limits, IP allowlists, deployment whitelists, and optional expiry dates.

🌊
True SSE streaming

Zero-buffer server-sent event proxy. First-token latency matches the model directly — no middleware overhead.

🧩
LoRA adapter hot-swap

Hot-load fine-tuned adapters via the control-plane API. No pod restart, no downtime.

📋
Full audit log

Append-only log of every request with token counts, latency, model ID, and key ID for compliance.

🔄
Multi-engine

First-class vLLM and SGLang support behind a unified interface. Switch engines per deployment.

🌐
OpenAI compatible

Drop-in base URL replacement. Works with every OpenAI SDK, LangChain, LlamaIndex, and more.

Quick Start

Streaming inference in one API call

# Stream completions through your own gateway
curl https://gateway.your-domain.com/v1/chat/completions \
  -H "Authorization: Bearer sk-live_…" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "llama-3-8b-instruct",
    "messages": [{"role":"user","content":"Explain gradient descent"}],
    "stream": true,
    "temperature": 0.7
  }'
from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.your-domain.com/v1",
    api_key="sk-live_…",
)

stream = client.chat.completions.create(
    model="llama-3-8b-instruct",
    messages=[{"role": "user", "content": "Explain gradient descent"}],
    stream=True,
)

for chunk in stream:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.your-domain.com/v1",
  apiKey:  "sk-live_…",
});

const stream = await client.chat.completions.create({
  model:    "llama-3-8b-instruct",
  messages: [{ role: "user", content: "Explain gradient descent" }],
  stream:   true,
});

for await (const chunk of stream)
  process.stdout.write(chunk.choices[0]?.delta?.content ?? "");
# 1. Add prerequisites (cert-manager + KEDA)
helm repo add cert-manager https://charts.jetstack.io
helm install cert-manager cert-manager/cert-manager \
  --namespace cert-manager --create-namespace \
  --set installCRDs=true

# 2. Install openserve
helm install openserve \
  oci://ghcr.io/openserve/charts/openserve \
  --namespace openserve --create-namespace \
  --set domain=gateway.your-domain.com \
  --set google.clientId=YOUR_OAUTH_CLIENT_ID \
  --set postgres.host=10.10.0.5 \
  --set redis.host=10.10.0.6 \
  --set gcs.bucket=my-model-weights
